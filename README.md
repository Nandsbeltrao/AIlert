# AIlert

A web app designed to help women in vulnerable situations find support resources quickly and discreetly.

## The Problem

In dangerous situations, opening a safety app can put someone at greater risk. AIlert solves this with **Chameleon Mode** ,  a feature that disguises the interface as Luna, a fake cycle tracking app. Triple-click the Luna logo to return to AIlert.

## Features

- Dynamic resource search with real-time filtering
- Quick filter tags : emergência, jurídico, abrigo, apoio emocional
- Chameleon Mode with Luna disguise
- Animated UI with smooth transitions

## Tech Stack

React · TypeScript · CSS · Vite · Vercel

## Getting Started

```bash
git clone https://github.com/Nandsbeltrao/AIlert.git
cd AIlert/ailert-v2
npm install
npm run dev
```
